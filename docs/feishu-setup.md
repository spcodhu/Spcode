# 飞书机器人通道接入教程

> 面向 Spcode 桌面端用户。全程约 15–30 分钟，只需配置一次。
> 配套设计说明见《远程控制设计》4.8 节（`docs/remote-control-design.md`）。

飞书机器人通道让你直接在飞书里给电脑上的 agent 发指令、收回复、批准权限请求。它利用飞书开放平台的**长连接模式**，桌面端主动出站连接即可收发消息——无需公网 IP、无需域名、无需中继服务器。

采用 **BYO-app** 模式：每个人创建自己的飞书应用（企业自建应用，个人账号即可，无需企业认证，无需上架审核）。你的 App ID / App Secret 只保存在你自己的电脑上。

## ⚠️ 隐私提示（请先读）

此通道下，你输入的提示词与 agent 返回的内容将以**明文**经过飞书（字节跳动）的服务器，飞书平台理论上可见这些内容，**不是端到端加密**（聊天终端本身就是飞书客户端）。该通道不经过 Spcode 开发者的任何服务器——连接发生在你的电脑与你自己的飞书应用之间。

**处理敏感项目时，请改用端到端加密的 PWA 通道**（设置页「远程控制」总开关 + 扫码配对）。飞书通道默认关闭，开启即视为知悉并接受上述边界。

## 接入步骤

### 第 1 步：注册飞书并创建团队

如果你还没有飞书账号：到 [feishu.cn](https://www.feishu.cn) 注册，并按引导创建一个**免费团队**（团队就是飞书的"租户"，个人使用创建一个即可）。已有飞书账号和团队可跳过本步。

### 第 2 步：创建企业自建应用

1. 打开[飞书开放平台](https://open.feishu.cn)，用你的飞书账号登录；
2. 进入「开发者后台」→「创建企业自建应用」；
3. 填写应用名称（如"我的电脑助手"）与描述，图标随意。

企业自建应用**个人账号即可创建**，无需企业认证、无需官方审核、无需 ICP 备案——它只在你自己的团队内可用。

### 第 3 步：添加机器人能力

在应用管理页左侧找到「添加应用能力」→ 添加「**机器人**」。这样你的应用就有了一个可以私聊、可以拉群的机器人身份。

### 第 4 步：开通权限

在应用管理页左侧进入「权限管理」，开通以下 4 个权限：

| 权限 | 用途 |
| --- | --- |
| `im:message` | 读取消息内容（接收你的指令） |
| `im:message:send_as_bot` | 以机器人身份发送消息（回复你） |
| `im:chat:readonly` | 读取会话信息（区分私聊/群聊） |
| `contact:user.id:readonly` | 读取用户 ID（绑定授权用户白名单） |

**快捷方式**：权限管理页面提供「批量导入权限」功能，直接粘贴下面这段 JSON 一次导入：

```json
{
  "scopes": {
    "tenant": [
      "im:message",
      "im:message:send_as_bot",
      "im:chat:readonly",
      "contact:user.id:readonly"
    ],
    "user": []
  }
}
```

### 第 5 步：配置事件订阅（长连接）

1. 在应用管理页左侧进入「事件订阅」；
2. 接收方式选择「**使用长连接接收事件**」（不要选 webhook——长连接模式无需公网回调地址）；
3. 添加事件：**接收消息 `im.message.receive_v1`**。

> 注意：保存长连接配置时，飞书会校验你的应用是否能建立长连接。请先确保 Spcode 桌面端**已启动、飞书通道已开启并填入凭证**（第 7 步），再回到本步保存；否则可能提示校验失败。若顺序颠倒，保存失败后在桌面端重启一次飞书通道（关闭再开启开关）即可。

### 第 6 步：创建版本并发布

在应用管理页「版本管理与发布」中**创建版本**（版本号随意，如 1.0.0）并提交发布。企业自建应用的发布由租户管理员审批——你自己就是管理员，进「管理后台」**自己批准自己**即可，通常即时生效。

### 第 7 步：把凭证填进 Spcode 设置页

1. 在开放平台应用管理页的「凭证与基础信息」中，复制 **App ID**（`cli_` 开头）与 **App Secret**；
2. 打开 Spcode →「设置」→「远程控制」→「飞书机器人」分区；
3. 开启「飞书机器人通道」开关，填入 App ID 与 App Secret，点击「保存」；
4. 状态徽章变为「已连接」即表示长连接建立成功。

凭证只保存在你本机的 `~/.spcode/settings.json`（0600 权限），不会上传到任何服务器。

### 第 8 步：绑定你的飞书账号

出于安全考虑，机器人**只响应白名单内授权用户**的指令（防止同团队他人或误拉入群者操控你的电脑）：

1. 在飞书里找到你的机器人，私聊发送**任意一条消息**（如"你好"）；
2. 桌面端设置页会显示一个 **6 位绑定验证码**（5 分钟内有效）；
3. 在飞书私聊中发送 `/bind 验证码`（如 `/bind 123456`）；
4. 绑定成功后，该飞书账号即进入授权白名单，可以正常使用全部指令。

之后即可在飞书中：直接发消息创建/继续会话、收到权限批准卡片时点按钮批准、用 `/abort`、`/schedules`、`/new <任务>` 等斜杠指令管理会话与定时任务。

如需撤销某个账号的权限，在设置页「授权用户」列表中点击「解绑」即可。

## 常见问题

**Q：保存长连接配置时提示失败？**
A：长连接校验要求应用侧有在线连接。确认 Spcode 桌面端已启动、「飞书机器人通道」开关已开启且 App ID / Secret 已保存（状态徽章为「已连接」或「连接中」），再回到开放平台保存事件订阅配置。

**Q：我所在的企业/团队发布应用需要管理员审批？**
A：如果你用的是他人创建的企业团队（而非自己建的免费团队），发布自建应用可能需要该团队管理员审批。联系管理员批准，或改用第 1 步创建的自己的免费团队。

**Q：状态徽章显示「连接失败」？**
A：依次检查：App ID / App Secret 是否复制完整（无多余空格）；应用是否已发布并通过审批；事件订阅是否已选择「长连接」并添加 `im.message.receive_v1`；权限是否全部开通。修改后重新保存凭证会触发重连。

**Q：绑定验证码一直不出现？**
A：验证码只在「已连接」状态下、有新用户私聊机器人时生成。确认徽章为「已连接」后，在飞书私聊里先发一条普通消息，几秒内设置页即显示 6 位验证码。

**Q：App Secret 安全吗？**
A：App Secret 与 App ID 只保存在你本机 `~/.spcode/settings.json`（0600 权限，与你本机其他凭证同级保护），不会回传界面、不会上传。若怀疑泄露，在开放平台「凭证与基础信息」里重置 Secret 并更新到设置页即可。

**Q：这条通道的消息会被谁看到？**
A：飞书（字节跳动）服务器可以看到你发给机器人的提示词与机器人回复的全部明文（这是 IM 通道的固有属性，无法端到端加密）。Spcode 开发者**不在链路里**——连接是你的电脑 ↔ 你自己的飞书应用。敏感项目请使用端到端加密的 PWA 通道（见设置页「远程控制」与「远程功能隐私说明」）。
